# Ahmed Fawzy Abdelkader - Personal CV Website

A responsive personal portfolio created for Assignment 1 in Design of Web-Based Systems.

## Files

- `index.html` - semantic page structure and CV content
- `styles.css` - responsive styling and print rules
- `images/profile.jpeg` - profile photograph
- `assets/Ahmed_Fawzy_CV.pdf` - downloadable CV
- `link.txt` - intended GitHub Pages URL

## GitHub Pages deployment

1. Create a public repository named `ahmed-fawzy-cv` on the `Ahmed-Fawzy14` GitHub account.
2. Upload the contents of this folder to the repository root.
3. In **Settings > Pages**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)` folder, then save.
5. Verify that the URL in `link.txt` opens the published website.
